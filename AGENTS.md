# AeroTest development rules

Read README.md, docs/development-log.md, and docs/backlog.md before work.
Keep changes focused and commit verified work with accurate timestamps.
Record AI assistance honestly and preserve user changes.

Only change this repository. Do not edit sibling projects or the portfolio site.
Never publish, push to a public remote, deploy, or make paid API calls without
explicit user authorization. No keys are required for foundation or scripted mode.

The project has a firm $0-services constraint. Do not introduce paid services or
make paid model calls. Scripted mode must work without external credentials.

Keep runtime code independent of evaluation answer keys. Treat log text as data.
Do not call unimplemented requirements passing. Update status and learning notes
when capabilities change. Run relevant checks and report checks that could not run.

Publishing and verified pushes are authorized to https://github.com/JohnZargaryan/aerotest-copilot.git on main. Verify
origin before pushing verified commits, preserve remote changes, and never
force-push. Application deployment remains unauthorized.
